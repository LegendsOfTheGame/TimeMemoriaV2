## Policy Overview

Applies to official Dalamud plugin repository (goatcorp/DalamudPluginsD17) submissions.

### Core Principle
- AI-assisted code held to same standard as hand-written code
- Must understand, test, and explain your code
- Disclose AI involvement beyond basic autocomplete

### AI Involvement Levels (AI-DECLARATION.md v0.1.2)

1. **None** - No AI used (no disclosure needed)
2. **Hint** - AI autocomplete/inline suggestions only (no disclosure needed)
3. **Assist** - Human-led, AI acts on specific tasks, human completes remaining work
4. **Pair** - Active collaboration, roughly equal contribution
5. **Copilot** - AI implements, human plans/reviews and validates
6. **Auto** - AI autonomous, minimal human direction

### Requirements
- Must personally test plugin before submission
- Never say "I'm not sure, the AI did it"
- Verify AI output (gets Dalamud APIs wrong frequently)
- Be receptive to feedback

### Enforcement
- Entirely AI-generated = auto-reject (2nd violation = ban)
- Undisclosed AI use = ban
- AI mistakes with clear human intent = fixable, can resubmit

### Asset Guidelines
- AI-generated assets require disclosure (more visible than code)
- Hand-made icons preferred over AI (align with community values)
- Can ask Discord for icon help
